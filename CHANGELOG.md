# Changelog

## 0.1.0

First release.

- Sidebar tree of Next.js routes: App Router pages and route handlers, Pages Router pages and API routes.
- Sidebar tree of Express routes, with mount prefixes resolved inside a file and across files.
- Click a route to open the file at the line that defines it.
- Send a test request to a route and read the response in the output panel.
- Copy a route's path from the right-click menu.
